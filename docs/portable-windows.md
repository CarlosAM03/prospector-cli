# Prospector CLI v1.0.0 — Windows portable candidate

This Windows 10/11 x64 portable candidate requires **Microsoft Edge Stable installed on the machine**. Extract the entire folder to a writable, normal-user location and run `prospector.exe`. Keep `_internal/`, `LICENSE`, and the notice files beside the executable. The package includes the Python and Playwright application runtimes, but **no browser executable**; it needs neither a separate Python installation nor `playwright install`. Prospector does not install Edge automatically.

Choose New Search or Multiple Searches; review/edit input and confirm before execution, then select Visible (the default) or Background browser mode. Both use installed Edge. Website enrichment stays enabled. After the summary, use View Results for pages of ten or Export Results for CSV/XLSX. Exports are written to `exports/`, diagnostics to rotating files under `logs/`. Ctrl+C during execution asks whether to cancel; confirmed cancellation discards unexported results after browser cleanup. Closing the console window has only best-effort cleanup. If Edge cannot launch, the CLI reports an actionable error and writes technical details to `logs/`.

Only verified Google Maps identities can drive cross-query duplicate suppression. `UNVERIFIED` observations remain exportable and may appear commercially duplicated. Google Maps or websites may produce recoverable partial results. Enterprise-managed Edge policies, mandatory extensions, proxy settings or organizational controls may interfere with automation; Prospector does not bypass them. This candidate has no persistence, resume, auto-update, API, or SaaS component. An unsigned executable may produce Windows reputation warnings. See the repository README for source setup and detailed limits.

Release-candidate validation covered the primary Windows development host and relocated packaged execution. A separate clean Windows-machine test was deferred by owner decision to post-release compatibility validation; this candidate is not claimed universally verified and is not yet a published stable release.
