# Prospector CLI v1.0.0 — Windows portable candidate

This Windows 10/11 x64 portable candidate requires **Microsoft Edge Stable installed on the machine**. Once the GitHub Release is published, download `Prospector-CLI-v1.0.0-win64.zip` from this repository's Releases page; it is not public yet. Extract the entire folder to a writable, normal-user location and run `prospector.exe`. Keep `_internal/`, `LICENSE`, and the notice files beside the executable. The package includes the Python and Playwright application runtimes, but **no browser executable**; it needs neither a separate Python installation nor `playwright install`. Prospector does not install Edge automatically.

Choose New Search or Multiple Searches. Enter a keyword, location and limit per query (Enter defaults to 50; CLI maximum 100); interactive batches accept two or three sequential queries. Review, edit or go back before confirmation, then select Visible (the default) or Background browser mode. Both use installed Edge. Website enrichment stays enabled. During execution, global and source progress are displayed. Afterward, inspect per-query/batch metrics and summary, use View Results for pages of ten or Export Results for CSV/XLSX. Batch exports are independent per query. Exports are written to `exports/`, diagnostics to rotating files under `logs/`. Ctrl+C during execution asks whether to cancel: No continues; confirmed Yes discards unexported results after browser cleanup and returns to the menu. Choose Exit for a normal shutdown. Closing the console window has only best-effort cleanup.

If Edge cannot launch, verify that Microsoft Edge Stable is installed and can start for the current user; inspect `logs/` for technical detail and consult an administrator if enterprise policy blocks automation. Keep the whole extracted folder together and use a writable destination if exports or logs fail. An unsigned executable may produce a Windows reputation warning; inspect the release source and checksum before deciding whether to run it. Do not disable organizational security policy to bypass a block.

Only verified Google Maps identities can drive cross-query duplicate suppression. `UNVERIFIED` observations remain exportable and may appear commercially duplicated. Google Maps or websites may produce recoverable partial results. Enterprise-managed Edge policies, mandatory extensions, proxy settings or organizational controls may interfere with automation; Prospector does not bypass them. This candidate has no persistence, resume, auto-update, API, or SaaS component. See the repository README for source setup and [known limitations](releases/v1.0.0/KNOWN_LIMITATIONS.md).

Release-candidate validation covered the primary Windows development host and relocated packaged execution. A separate clean Windows-machine test was deferred by owner decision to post-release compatibility validation; this candidate is not claimed universally verified and is not yet a published stable release.
